# НАЗВАНИЕ ПРОЕКТА

Программа удаления заданного столбца из вещественной матрицы

## КРАТКОЕ НАЗНАЧЕНИЕ

Программа предназначена для обработки вещественных (дробных) матриц размерности n × m.

Основная функция — удаление столбца с номером k, который выбирает пользователь.

Программа может использоваться в учебных целях для изучения двумерных массивов и основ программирования.

## ТРЕБОВАНИЯ К ОКРУЖЕНИЮ

- Язык программирования: Python 3.x
- Операционная система: любая (Windows, Linux, macOS), поддерживающая Python
- Дополнительные библиотеки: не требуются
- Оборудование: любой компьютер, на котором установлен интерпретатор Python

## ИНСТРУКЦИИ ПО ЗАПУСКУ

1. Установите Python 3.x, если он ещё не установлен.
2. Сохраните исходный код программы в файл с расширением `.py`.
3. Откройте терминал (командную строку) и перейдите в папку с файлом.
4. Выполните команду:

```bash
python название_файла.py
```

5. Следуйте инструкциям программы.

В проекте используется упрощённый GitHub Flow. Ветка main содержит только стабильный, проверенный код. Разработка ведётся в ветке develop, от которой при необходимости создаются временные ветки для отдельных задач. После завершения работы над функцией изменения вливаются в develop, а затем, после проверки, — в main. Выбранная стратегия проста в освоении, подходит для небольших проектов и обеспечивает чёткое разделение стабильного и разрабатываемого кода без большого количества вспомогательных веток.
